# DC88_Win32
DeSmet C Cross Compiler for 8086/8088 [PASS1 (Win32 Port) - Alpha release]

* This port runs on Windows 32/64 bit and produces code for 8086/8088 for DOS

<b>Build Platform</b>  
OS : Windows 11 x64  
Toolchain : MSYS2 GCC 16.1.0 (MinGW32)  
Debugger : GNU gdb (GDB) 17.2  
IDE : Codeblocks 25.03  

C Test Suite : https://github.com/c-testsuite/c-testsuite.git
